Detailed Description

Assigns each team a paired golem+egg model, by arrival order, cycling past the last theme.

Teams are registered in the order the server announces them; this registry maps the n-th team to the n-th theme. When there are more teams than themes, the assignment wraps around (team 5 reuses theme 1, etc.).
