Detailed Description

Command-line argument parser with runtime flag registration.

Flags must be registered with registerFlag() before calling parse(). Values are then retrieved through the typed getters (getInt, getString, getList). Example:

zappy::ArgParser parser(argc, argv);
parser.registerFlag("-p", zappy::FlagType::INT, true, "port");
parser.registerFlag("-n", zappy::FlagType::LIST, true, "team names");
parser.registerFlag("-c", zappy::FlagType::INT, false, "client nb");
parser.parse();
int port = parser.getInt("-p");
auto teams = parser.getList("-n");

void zappy::ArgParser::parse ( )

Parses argv against all registered flags.

Iterates argv, matches each -flag against registered configs, consumes its value(s), then verifies all required flags are present.
