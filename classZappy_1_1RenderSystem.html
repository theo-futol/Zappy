◆ groundTile()

bool Zappy::RenderSystem::groundTile ( double  px,
double  py,
const GameState &  state,
int &  tileX,
int &  tileY 
) const
private

Finds the tile under a screen point by projecting every tile and taking the nearest one.

Screen-space picking: each tile center is projected to the screen; among the tiles whose projection lands within a pixel radius of the cursor, the one closest to the camera (front face of the torus) wins. Works on any curved surface, unlike a ray-plane intersection.

Parameters
pxScreen X in pixels.
pyScreen Y in pixels.
stateState read for the map dimensions and projection.
tileXReceives the hit tile X.
tileYReceives the hit tile Y.
Returns
True if a tile was found under the cursor, false otherwise.
