◆ drawInstanced()

void Zappy::Mesh::drawInstanced ( const std::vector< Mat4 > &  instances) const

Draws the mesh many times in one call, one copy per instance matrix.

Uploads the per-instance model matrices to a dedicated buffer wired as vertex attributes (a mat4 occupying the four locations right after the vertex attributes), each advancing once per instance, then issues a single glDrawElementsInstanced. The bound shader must read that instance matrix.

Parameters
instancesModel matrix of each instance; nothing is drawn if empty.

Uploads interleaved vertex and index data to the GPU.

Parameters
verticesInterleaved vertex attributes (all attributes of one vertex, then the next).
indicesElement indices.
attributeSizesComponent count of each attribute, in layout order (e.g. {3} for position-only, {3, 3, 2} for position + normal + uv). Attribute i is bound to shader location i.
Exceptions
MeshExceptionOn empty data, empty layout, or a vertex count that is not a whole multiple of the per-vertex stride.
