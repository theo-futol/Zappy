Detailed Description

A decoded Model uploaded to the GPU and ready to draw.

Built from a CPU-side Model and an AssetCache: it interleaves each primitive into a {3, 3, 2} mesh, flattens the node hierarchy into a list of draw items (each with its world transform), and computes a bounding sphere for framing.

Expands the bounds over the bind-posed vertices of a skinned model.

A skinned vertex is rendered as Σ weight_i · bindJoint(joint_i) · position, which may differ markedly in scale from the raw position (e.g. a model imported in cm). The framing bounds must be measured on those posed vertices, not the raw ones.

Parameters

boundsMinRunning minimum corner, expanded in place.
boundsMaxRunning maximum corner, expanded in place.

void Zappy::RenderModel::buildSkin ( const Model &  model)

Builds the rest-pose joint matrices and re-fits the bounds from raw vertices.

For a skinned model the rendered vertices live in skin space (the node transforms are ignored), so the bounding box is taken from the raw positions and the joint matrices are globalBind(joint) * inverseBind(joint) (identity at rest).

Parameters
modelSource model (must have at least one skin).

void Zappy::RenderModel::drawInstanced ( Shader &  shader,
const std::vector< Mat4 > &  bases 
) const

Draws the model once per base transform, in one instanced call per part.

For every part (primitive) it builds the per-instance model matrices (each base composed with the part's node transform) and issues a single instanced draw. All bases must share the same scale/rotation so one shared normal matrix is correct; only their translation may differ.

Parameters
shaderPhong shader, already bound and given the frame uniforms.
basesOne base transform per instance (e.g. one per tile or per entity).

◆ footprintTransform()

Mat4 Zappy::RenderModel::footprintTransform ( ) const

Transform that fits the model's horizontal footprint to one tile, lying flat.

Centers the model on the origin, scales its X and Z extents to one tile each (proportional height), and puts its top at y = 0. Suited to flat ground tiles that other models stand on. Compose it with a tile world position to tile the ground.

Returns
The footprint-fit transform.

Mat4 Zappy::RenderModel::unitTransform ( ) const

Transform that fits the raw model into a unit footprint standing on the ground.

Centers the model horizontally on the origin, drops its base to y = 0, and scales it so its largest extent equals one tile. Compose it with a tile world position to place the model on that tile.
