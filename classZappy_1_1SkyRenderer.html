Detailed Description

Draws the surrounding sky from a cube-map, behind everything else.

Renders a unit cube centered on the camera, sampling the cube map in the direction of each vertex. The view matrix is stripped of its translation so the sky never gets closer, and depth writes are disabled while drawing so the scene always paints on top. Meant to run first in the render order.
