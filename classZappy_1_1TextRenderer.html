Detailed Description

Renders text using FreeType; the only place FreeType is touched.

On load it rasterizes each printable ASCII glyph to a GL_RED texture and caches it with its placement metrics. drawText then emits one textured quad per glyph in screen space, sampling the glyph coverage as alpha.
