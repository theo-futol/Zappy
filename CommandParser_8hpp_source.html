15 /// @brief A command waiting in a client's queue together with the time it may run.
16 ///
17 /// Many commands take in-game time to complete, so they are not executed on arrival
18 /// but when steady_clock reaches readyAt.
19 struct PendingCommand
20 {
21 std::string line; ///< Raw command line as received.
22 std::chrono::steady_clock::time_point readyAt; ///< Earliest time the command may execute.
23 };

25 /// @brief Per-client command pipeline: reads socket data, splits it into commands,
26 /// and runs them at the right time according to their in-game duration.
27 ///
28 /// Each client gets its own CommandParser. It holds the command tables (one for AI
29 /// clients, one for graphic clients) and turns each parsed line into a call on the
30 /// shared Commands object.

44 /// @brief Reads pending data from the client socket into the command queue.
