Detailed Description

Top-level server object: owns the world and the network handler and wires them together from the parsed command-line arguments.

Typical lifecycle: construct with an ArgParser, then call run(), which builds the world and client handler and enters the blocking network loop until a signal flips serverIsRunning to false.
