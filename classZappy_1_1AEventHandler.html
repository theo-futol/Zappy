Detailed Description

Abstract base for protocol handlers; factors the shared parsing helpers.

Concrete handlers implement keys() and handle(); this base provides only static, defensive parsing utilities, so the conversion logic lives in a single place (§3.2). No helper throws: malformed input falls back to a safe default.
