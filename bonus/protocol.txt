Response protocol
==================

Every answer you give must start with exactly one of the following two
commands, and nothing else before it:

USE <tool_name>
    Use this when you want to perform an action through one of your
    available tools. <tool_name> must exactly match the name of one of
    the tools you have been given access to. The program will run that
    tool using your current agent profile and give you back its result.

REPORT <text>
    Use this when you have nothing to do through a tool right now and
    simply want to report back. <text> is appended to your own answer
    and shown to whoever is reading it.

Rules:
- Always start your answer with "USE " or "REPORT ", nothing else before it.
- Pick exactly one tool name per USE command, and never invent a tool
  name that was not given to you.
- Never combine USE and REPORT in the same answer.
- If you are unsure whether a tool applies, prefer REPORT over USE.
