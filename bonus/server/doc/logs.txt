Zappy server logs - implementation status
===========================================

Format (see Logger::log, Logger/Logger.hpp):
  code - message (key=value, key=value)
The "(...)" group is omitted when there are no fields.

Naming convention for 01x (Commands):
  This block has more than 10 commands, but each code is only 3 characters
  (1 digit + 2 chars) and the BNF code grammar is "3DIGIT / 4DIGIT", so once
  the decimal digits 010-019 are used up, the block continues counting in hex
  for the last character: 01A, 01B, 01C (i.e. 010..019 then 01A, 01B, 01C...).
  Same idea would apply to any other xxx block that needs more than 10 codes.
