Detailed Description

Per-client command pipeline: reads socket data, splits it into commands, and runs them at the right time according to their in-game duration.

Each client gets its own CommandParser. It holds the command tables (one for AI clients, one for graphic clients) and turns each parsed line into a call on the shared Commands object.
